# Antigravity CLI (agy) Prompt Contracts and Directory Standards

## 1. Directive Prefix Taxonomy

Prompts passed to `agy` must begin with an explicit directive tag that calibrates the reasoning mode and operational boundaries:

| Directive Tag | Reasoning Profile | Target Operational Scope | Output Routing |
| :--- | :--- | :--- | :--- |
| `[HOSTILE-AUDIT]` | Maximum security skepticism | Hardcoded tokens, shell injections, path traversal | `reports/audits/security_audit_*.md` |
| `[DEAD-CODE-PURGE]`| Call-graph tracing | Uncalled functions, dead imports, orphan variables | `dev/dead_code.md` |
| `[BEJSON-104]` | Tabular schema integrity | 6 mandatory keys, positional parity, null padding | `reports/audits/bejson_audit_*.md` |
| `[BEJSON-104A]` | Flat configuration | Primitive types, PascalCase metadata, key-value | `target/schemas/*.104a.bejson` |
| `[BECSS-BEM]` | Tri-color and UI layout | #000000, #FFFFFF, #DE2626, 8-lane grid, Ry=32px | `reports/audits/becss_audit_*.md` |
| `[SURGICAL]` | Minimal diff changes | Preserve code style, zero external dependencies | Targeted source files |
| `[PLAN]` | Non-mutating analysis | Step-by-step blueprints, impact assessments | Markdown plan outputs |

## 2. Standardized Subdirectory Routing

All outputs generated by `agy` tasks must map strictly to the canonical project tree:

- `reports/`: Architecture overviews, dependency graphs, health summaries.
- `reports/audits/`: Formal security reviews, dead-code logs, schema audits.
- `dev/`: Append-only living logs (`security-notes.md`, `dead_code.md`).
- `target/ideas/`: 25 to 50 point feature menus, CLI flag brainstorms.
- `target/schemas/`: BEJSON 104/104a schemas, agent instruction files.

## 3. Minute-Based Scheduling Configuration

Daemons and background loops must express timing parameters in integer minutes:

```bash
INTERVAL_MINUTES=5       # Nominal cycle delay
MIN_MINUTES=3            # Lower jitter bound
MAX_MINUTES=8            # Upper jitter bound
HEARTBEAT_MINUTES=15     # Health-check telemetry interval
```
