1. Parser Ingestion Architecture & Title Extraction

The BEJSON CMS ingestion engine operates through extract_from_html(html_bytes) inside src/web/BEJSON_CMS_Content.py. Understanding its extraction sequence guarantees that imported articles preserve complete structural fidelity:

Title Extraction Priority: The parser first queries the document <title> element. If present, its inner text becomes the canonical meta_title and page_slug. Only if <title> is missing does the parser fall back to scanning for an <h1>. Therefore, declaring a clean <title> tag in the head guarantees deterministic naming.

Body De-Noising: Upon ingestion, the parser automatically deconstructs <script>, <style>, <noscript>, <link>, and <meta> tags from the body. It then extracts soup.find('body') or soup and commits the inner HTML into the per-page 104db content record (storage/mfdb/pages_db/<uuid>.json).

4. Code Block Formatting & O(1) Field Map Caching

Technical articles in the CMS frequently present code algorithms. The optimal format uses standard <pre><code> wrappers with horizontal overflow scrolling: 

# Mandatory Policy Section 6.2 O(1) Field Map Cache Compliance
def read_cms_page_manifest(manifest_bejson: dict) -> list:
    fields_list = manifest_bejson.get("Fields", [])
    # Build dynamic O(1) lookup cache
    field_map = {field_def["name"]: col_idx for col_idx, field_def in enumerate(fields_list)}
    
    slug_idx = field_map.get("page_slug")
    title_idx = field_map.get("page_title")
    
    pages = []
    for row in manifest_bejson.get("Values", []):
        pages.append({
            "slug": row[slug_idx],
            "title": row[title_idx]
        })
    return pages

7. Zero Watermark & Sanitization Hygiene Checklist

Before committing or importing any HTML file into the CMS, ensure compliance with these core validation gates:

  • Zero Forbidden AI Watermarks: The import filter rejects or strips paragraphs matching terms like "generated by", "created with", or proprietary AI brand names.
  • Zero Microsoft Word Junk: Never paste raw Word documents without stripping o:p namespace tags and MsoNormal inline styles.
  • Self-Contained Image Paths: Reference images relatively or point to default_brand_assets/ or images/.
  • Single Root Article Container: Wrap content within <article class="bejson-cms-article"> for clean DOM boundary encapsulation.
